# Para Linda 💛

Dedicatoria de flores amarillas para Linda.

## Cómo abrirlo

Abre `index.html` en cualquier navegador moderno. El diseño se adapta a celulares, tablets y computadoras.

## Publicarlo con GitHub Pages

1. Entra a **Settings > Pages** dentro del repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/ (root)`.
4. Guarda los cambios y espera a que GitHub genere el enlace público.
